# Contributing

Identify the candidate and evidence status for each proposed change. Include a direct source for literature claims. For new project findings, include the [provenance record](records/run-template.json) and a reproducible path to raw evidence. Review atom labels, units, uncertainty, and signs before merging. Report unsuccessful work when it informs candidate selection.

Run `python3 scripts/linewidth.py` as a quick arithmetic check. Any future software-dependent workflow should record its tested version and inputs before claiming it can be reproduced.

Quantvaria Labs has yet to specify a redistribution licence for this repository. Check ownership and permissions for code, coordinates and data before a future public release. Cite original sources when discussing their reported results.
